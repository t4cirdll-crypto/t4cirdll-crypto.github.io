# Ночной сторож — Паук против Человека

Ты — крошечный домашний паук, который всю ночь защищает сон человека от комаров из окна. Плети паутину и оставайся незаметным. **Победа — дожить до 06:00.** Поражение наступает, если человек проснётся от укусов или заметит движение паука.

Игра работает в браузере на JavaScript ES modules и **Three.js 0.187.0 / WebGL 2**. Это объёмная спальня с ортографической камерой, мягкими тенями и матовыми материалами. Сцена занимает всю область браузера; кнопка «Во весь экран» перед стартом позволяет скрыть и панели браузера. Геометрия игры не растягивается и не обрезается при изменении размера окна.

Библиотека лежит локально в `vendor/` вместе с MIT-лицензией: CDN, внешние шрифты, модели, сетевые API и сборка для запуска не нужны. Для игры устанавливать Node.js или npm-пакеты не требуется.

## Запуск

Понадобятся установленный **Python 3.7 или новее** со стандартным модулем `http.server`, современный браузер и клавиатура.

1. Открой терминал в корне проекта — папке, где находятся `index.html` и `serve.bat`.
2. Запусти локальный HTTP-сервер:

   ```text
   python scripts/serve.py --port 8000
   ```

3. Пока сервер работает, открой **http://localhost:8000/** в браузере.
4. Нажми **Enter**, чтобы начать ночь. Оставь окно терминала открытым во время игры.

Для остановки сервера нажми **Ctrl+C** в терминале. Сервер предназначен для локального запуска, а не для публикации игры в интернете; не размещай в обслуживаемой папке секретные файлы.

### Windows: запуск двойным щелчком

Открой `serve.bat` двойным щелчком. Он перейдёт в каталог самого файла независимо от исходной рабочей папки, проверит Python 3.7+ и попробует запустить сервер на порту **8000**. Если он занят или недоступен, сервер выберет свободный локальный порт и сообщит об этом. Дождись строки **`Project preview: http://127.0.0.1:ПОРТ/`** и открой именно показанный адрес. `http://localhost:8000/` подходит только если сервер действительно занял порт 8000.

Если команда `python` недоступна или не подходит, будет использован Windows launcher `py -3`. Другие процессы BAT не останавливает. Чтобы задать строго определённый порт, запусти из терминала:

```text
serve.bat 8001
```

В этом случае открой **http://127.0.0.1:8001/** после появления `Project preview`. Явно указанный порт не заменяется автоматически: при ошибке окно покажет пояснение и дождётся нажатия клавиши. Сохраняй `serve.bat` с переносами строк **Windows CRLF**, UTF-8 без BOM: LF может приводить к неверному чтению команд в `cmd.exe`.

Если Python не найден, окно покажет пояснение и останется открытым до нажатия клавиши. Установи Python 3, включив добавление в `PATH`, либо установи Windows launcher `py`, затем открой `serve.bat` снова. Никаких дополнительных пакетов для игры не требуется.

При доступном launcher можно также запустить сервер из корня проекта вручную:

```text
py -3 scripts/serve.py --port 8000
```

### Почему не достаточно открыть index.html

При двойном щелчке по `index.html` браузер открывает адрес `file://`. Игра импортирует JavaScript ES modules; загрузка модулей из локальных файлов ограничивается политикой безопасности браузера и может блокироваться. Нужен HTTP-адрес: локальный сервер корректно раздаёт HTML, стили и модули. Не отключай защиту браузера — используй **http://localhost:8000/**.

### Если игра не открывается

- **Команда `python` не найдена:** проверь установку Python 3 и `PATH`; на Windows попробуй `py -3` или `serve.bat`.
- **Порт 8000 занят:** двойной щелчок по `serve.bat` автоматически выберет свободный порт. При ручном запуске можно использовать `python scripts/serve.py --port 8000 --fallback-port` или явно выбрать `serve.bat 8001`. Не останавливай неизвестный процесс.
- **Вместо игры список файлов или ошибка 404:** проверь, что открыл именно адрес из строки `Project preview`, а не другой сервер на порту 8000. `serve.bat` и `scripts/serve.py` всегда обслуживают каталог игры.
- **Браузер не подключается:** убедись, что сервер не остановлен, и проверь сообщения в его окне. Адрес должен совпадать со строкой `Project preview` и начинаться с `http://`, не `https://` и не `file://`.

## Управление

| Клавиши | Действие |
| --- | --- |
| **WASD** или **стрелки** | Двигаться |
| **Space**, удерживать | Плести паутину |
| **Shift**, удерживать | Замереть |
| **P** или **Esc** | Пауза / продолжить |
| **M** | Включить / выключить звук (когда фокус на сцене) |
| **Enter** | Начать выбранную ночь / повторить после поражения / продолжить после выбора награды |

Играй в активной вкладке браузера. Сенсорное управление не реализовано: для игры нужна клавиатура.

## Кампания: шесть ночей и бесконечный дозор

Полное прохождение без поражений — **25 минут активной игры**, не считая пауз и выбора способностей. Поражение повторяет только текущую ночь.

| Ночь | Длительность | Условия |
| --- | --- | --- |
| Первый дозор | 3:30 | Обычные комары, освоение защиты |
| Открытая форточка | 3:45 | Сквозняк и быстрые серебристые комары |
| Чуткий сон | 4:00 | Дождь, частые взгляды и тяжёлые медные комары |
| Сезон охоты | 4:15 | Парные наплывы и более проворный богомол |
| Хрупкий шёлк | 4:30 | Нити живут на 22% меньше, смешанные стаи |
| До последней звезды | 5:00 | Ливень, ветер и все угрозы |

Внутри каждой ночи чередуются волны и передышки. С четвёртой ночи отдыха меньше: 20% времени против 36% в ранних ночах. Во время наплывов каждая третья группа выходит парой. Скорость мира не ускоряется, замах богомола и предупреждение человека остаются прежними. Погода видна в окне, слышна в атмосфере; начало волн и передышек отмечается разными звуковыми мотивами без текстовых баннеров.

После каждого **нового** рассвета выбери одну из трёх способностей. Всего восемь видов, максимум два уровня каждого: запас/восстановление шёлка, липкость и срок жизни сети, скорость, незаметность, защита сна, шёлк за добычу. Улучшения реально меняют параметры следующей ночи и сохраняются при поражении. Повтор уже пройденной ночи улучшает рекорд, но не выдаёт ещё одну награду. В журнале можно выбрать любую открытую ночь.

После шестого рассвета открывается **«За гранью рассвета»**: пятиминутные циклы со сменой условий и растущим до ограниченного максимума натиском. Все шесть выбранных улучшений остаются. Между циклами сохраняется прогресс, но новых бесконечных наград нет.

Комары целятся не только в лицо, но и в открытую кисть и ступню: просто стоять у подушки весь раунд недостаточно. Насытившийся комар после трёх укусов летит обратно к окну; его всё ещё можно поймать, но за самостоятельный отлёт награда не выдаётся. Пропущенная стая опасна, однако один комар больше не накапливает урон бесконечно. Лови их на подходе и собирай застрявших до освобождения. Удерживай Shift при взгляде человека. Подсказки и журнал скрываются в игре, остаются четыре шкалы.

### Сохранение и перенос

Кампания автоматически сохраняется **между ночами** в `localStorage` (`nightwatch.campaign.v1`): открытые ночи, способности, рекорды, выбранная ночь, бесконечный цикл и незабранная награда. Перезагрузка во время дозора начинает эту ночь заново с теми же способностями. Незабранная награда и предложение мини-игры после рассвета восстанавливаются даже после выбора улучшения. Незаконченная мини-игра после перезагрузки предлагается заново; завершённая награда повторно не начисляется. Ошибка или запрет хранилища не останавливает игру, но экран предупреждает, что прогресс временный.

Сохранение принадлежит браузеру и **точному адресу, включая порт**. `localhost` и `127.0.0.1` — тоже разные адреса. Если `serve.bat` выбрал другой свободный порт, открой прежний адрес или перенеси файл: **«Сохранение и перенос» → «Скачать сохранение»**, затем **«Загрузить сохранение»** на новом адресе. Импорт доступен только в журнале, проверяет формат и заменяет кампанию. Неверный файл не меняет текущие данные. Скачанный JSON можно хранить независимо от браузера.

## Паутина и богомол

- **Шёлка больше:** запас 220, восстановление 6/с, комар возвращает 32. Одна полная катушка — примерно 1570 пикселей основных нитей без учёта восстановления. Поворотные перемычки также расходуют шёлк.
- Удерживай **Space** и меняй направление: на поворотах и рядом с уже сплетённой сетью паук вплетает тонкие диагональные перемычки. Они стоят 55% от расхода несущей нити. Это настоящие ловушки, а не декоративные линии. Нити объёмные, со скрученным волокном и мягким перламутровым бликом; толщина увеличена в 2,5 раза вместе с волокнами и узлами (`CFG.web.thicknessScale`). Перемычки остаются тоньше несущих нитей, последние секунды жизни шёлк постепенно истончается. Оси ловушек и расход шёлка не меняются.
- В комнате живёт **богомол**. Первые 2 секунды он даёт на подготовку, затем каждые 0,2 секунды ищет прямые непрерывные пролёты от 110 пикселей. Он подходит со скоростью 145–175 пикселей/с и отдыхает между атаками всего 0,65 секунды после жевания. Предупреждающий замах длится 1,1 секунды. Много коротких отрезков в одну линию считаются одним пролётом.
- Перед укусом он подбирается к цели, поднимает клешни и отмечает область тёплым кольцом. **Радиус укуса — 44 пикселя (диаметр 88 вместо прежних 38)**: срезаются все живые нити внутри круга, включая соседние и перемычки, но наружные части остаются. Кольцо показывает реальный радиус, а не условную точку. Богомол не убивает паука: его угроза — дырки, через которые проходят комары.
- Плети зигзаги, треугольники и короткие пролёты, соединяй нити. Настоящий поворот, развилка или пересечение разбивают пролёт. Длинный прямой хвост за единственной развилкой всё ещё уязвим. Перестройка сети во время подхода может отменить атаку.
- Пауза останавливает обоих врагов и переливы шёлка. В активном раунде по-прежнему только четыре шкалы; правила показаны перед первым стартом.

## Паук-охотник

- Если **новая живая нить проходит в пределах 54 пикселей от лица или тела человека** (раньше 88), из-за кровати выходит отдельный паук-охотник. Проверяется весь отрезок, включая перемычки; просто ходить рядом, держать Space без плетения или иметь старую паутину недостаточно. Разрывы богомола не считаются новым плетением.
- При плетении рядом с кроватью тихий янтарный контур показывает настоящую границу опасного плетения. Он исчезает вдали и при отпускании Space; текстовых баннеров нет. Радиус корпуса охотника уменьшен с 13 до 8 пикселей: поимка при дистанции 17, а не 22 пикселя с учётом игрока. Длинные лапы не считаются хваткой.
- Перед погоней — **1,25 секунды появления и янтарное кольцо**. Место выхода не ближе 180 пикселей к игроку; охотник крупнее и темнее домашнего паука. Одновременно существует только один охотник.
- Он преследует игрока со скоростью 98–112 пикселей/с, разгоняется и не может мгновенно разворачиваться. Игрок быстрее даже при плетении (125 пикселей/с). Контакт заканчивает раунд с отдельной причиной поражения. Замереть в обычной погоне не спасает.
- **Оторвись на 280 пикселей и удержи дистанцию 3 секунды**: охотник уйдёт к кровати. Через 4 секунды после ухода он снова сможет услышать новое плетение у спящего. Старые нити сами его не вызывают.
- Когда человек шевелится или смотрит, охотник тоже замирает: остаётся возможность пользоваться Shift и не попасть под тапок. После взгляда погоня продолжается. Пауза, потеря фокуса и новый раунд корректно останавливают/сбрасывают охотника.
- Паук-игрок — объёмная модель с выпуклым брюшком и грудью, восемью суставчатыми лапами, приподнятыми коленями, глазами, пальпами и мягкими бликами. В движении корпус покачивается, лапы поднимаются поочерёдно; геометрия переиспользуется, коллизии и управление не изменены.

## Читаемость и утренняя роса

У застрявшей добычи появляется спокойное шалфейное кольцо, у кусающей — тёплый пульс. Это метки внутри сцены; во время ночи всё ещё только четыре шкалы. Экран поражения объясняет конкретную причину и подсказывает тактику для следующей попытки.

После улучшения можно сыграть 25 секунд в «Утреннюю росу»: A/D, стрелки или мышь двигают паука по нити. Капли и мухи дают очки, сухие листья оглушают и снимают три очка. Серия сбрасывается сразу после пропуска капли за линию ловли, а не с задержкой за экраном. Награда — до 150 дополнительного шёлка сверх запаса на следующую ночь, включая её честные повторы. Мини-игру можно пропустить.

## Локальное админ-меню

Введи ник **killdev** и нажми **«Сохранить»**. Регистр не важен. В меню и на паузе появится кнопка **«Админ-меню»**, в раунде панель открывается клавишей **F2**. Она ставит ночь на паузу и не добавляет элементов в обычный HUD. **Esc / F2** закрывают панель; **P** продолжает ночь после закрытия. В мини-игре панель недоступна.

- Переключатели: бессмертие (сон, обнаружение и охотник), бесконечный шёлк, заморозка угроз и появления врагов.
- Команды текущей ночи: восстановить сон/шёлк и снять подозрение, убрать врагов, перейти к одной из четырёх волн, перезапустить ночь, вызвать рассвет. Рассвет ведёт к обычному выбору улучшения и мини-игре.
- **Песочница:** при входе копируется настоящая кампания, но админские победы, награды и рекорды не записываются в неё или зал славы. Перезагрузка сбрасывает эксперименты; смена ника возвращает исходную кампанию. Ник сохраняется, переключатели — нет.

Это намеренный локальный чит в однопользовательской игре, не механизм серверной авторизации. Режим **Sharrowkin ×3** остаётся отдельным и не даёт админ-доступа.

## Звуковая система

Звук процедурно синтезируется через **Web Audio API**: никаких аудиофайлов, скачиваний, CDN или дополнительных npm-пакетов. Это тихая ночная звуковая среда, а не готовый музыкальный саундтрек.

- **Комната:** приглушённый шум за окном, дыхание спящего, мягкий двухголосный фон. При подозрении человека и погоне добавляется низкий пульс напряжения.
- **Паутина и игрок:** шорох лап, протягивание шёлка, более звонкая перемычка, натяжение при поимке, обрыв, поедание комара и однократный сигнал малого запаса шёлка. Удерживать Space без создания нити недостаточно для звука плетения.
- **Живые угрозы:** стереожужжание до пяти комаров одновременно; шорох ткани перед взглядом; отдельные предупреждения богомола и охотника, хруст кругового укуса, шаги охотника и сигнал отрыва. Финалы различаются: рассвет, пробуждение, тапок, поимка охотником.
- **Стерео:** положение источника в комнате определяет левый/правый канал; жужжание становится заметнее рядом с игроком. Это экранное стереопанорамирование, не HRTF/объёмное аудио наушников.

**Настройки находятся перед стартом и на паузе:** общий уровень, атмосфера, эффекты, выключатель и кнопка «Проверить звук». Клавиша **M** переключает звук без новой плашки в игровом HUD. Уровни по умолчанию: 65% / 65% / 80%. Настройки сохраняются локально в браузере; запрет хранилища не мешает играть.

Браузер разрешает звук только после действия пользователя. Старт кнопкой, Enter или щелчком по сцене разблокирует аудио; до этого страница молчит. Пауза, потеря фокуса и скрытие вкладки выключают игровой микс и приостанавливают AudioContext. Возврат во вкладку сам игру не продолжает. Кнопка проверки может ненадолго воспроизвести отдельный пример на паузе, не запуская ночь. После финального мотива аудиоустройство тоже приостанавливается. Рестарт обрывает старые эффекты, а отключённый звук не копит события для последующего воспроизведения.

Одновременно работает не более 32 слоёв коротких эффектов; их узлы отключаются по завершении, общая громкость защищена компрессором. Модель игры не зависит от AudioContext: если устройство или Web Audio недоступны, игра остаётся рабочей без звука и панель сообщает причину.

## Структура проекта

- `index.html`, `style.css` — HTML-оболочка и её оформление.
- `src/config.js` — баланс и геометрия комнаты.
- `src/game.js` — состояния и игровая логика.
- `src/entities/` — паук, паутина, комар, человек, богомол, паук-охотник и граф реальных соединений сети.
- `src/render.js`, `src/view/` — 3D-сцена, камера, спальня, персонажи и реальные нити паутины.
- `src/ui.js` — стартовый экран, шкалы состояния, пауза и результаты.
- `src/sound/` — очередь модельных событий, сохранение уровней, аудиограф, синтез эффектов, микшер и настройки звука.
- `src/progression/` — ночи и волны, улучшения, кампания/валидация сохранений, перенос файлом и оформление экранов.
- `src/input.js`, `src/math.js`, `src/main.js` — ввод, утилиты и игровой цикл.
- `vendor/` — закреплённый локальный Three.js и его лицензия.
- `serve.bat`, `scripts/serve.py` — локальный HTTP-сервер Python с очередью для параллельной загрузки модулей.

## Разработка и проверки

Нужен Node.js **22.12.0 или новее**, npm 10.9.4. На проверенной машине — Node.js 22.22.1.

```text
npm ci --ignore-scripts
npm run vendor
npm run check
npm test
python tests/test_launcher.py
```

`tests/test_launcher.py` проверяет реальный BAT через `cmd.exe`: запуск из другой папки, резервный порт, `py -3`, отсутствие Python, занятый/неверный порт и загрузку HTML/JS по HTTP. Процессы, запущенные проверкой, останавливаются после неё. Полный набор BAT-проверок требует Windows.

`vendor/` уже включён в проект, его обновление нужно только при замене версии Three.js. Версии закреплены в `package-lock.json`.

Браузерная регрессия использует установленный Microsoft Edge и настоящий клавиатурный ввод (Playwright). При работающем сервере:

```text
node scripts/check-browser.mjs http://127.0.0.1:8000/
node scripts/check-silk-browser.mjs http://127.0.0.1:8000/
node scripts/check-hunter-browser.mjs http://127.0.0.1:8000/
node scripts/check-sound-browser.mjs http://127.0.0.1:8000/
node scripts/check-campaign-browser.mjs http://127.0.0.1:8000/
```

`node scripts/simulate-campaign.mjs` прогоняет все шесть ночей обычными шагами 1/60 секунды, без перемотки таймера или подмены врагов. Тестовый контроллер использует настоящий модуль ввода, выбирает предложенные способности, повторяет поражения и загружает сохранение между ночами. Отдельно проверяются проигрыш при стоянии у подушки, волны/передышки и лимиты количества нитей/комаров. Это воспроизводимая проверка длительности и технической проходимости, не оценка сложности человеком. Можно передать числовой seed вторым аргументом.

Сценарий кампании в браузере проверяет журнал, шесть экранов награды, повтор/продолжение после перезагрузки, финал, бесконечные циклы, настоящий экспорт/импорт JSON, погоду/звуки волн и экраны от 390 до 1440 пикселей. В этой проверке финалы ускоряются установкой часов перед последним шагом — длинная симуляция вынесена в отдельную команду выше.

Звуковая регрессия проверяет настоящий Web Audio: ненулевой конечный PCM всех эффектов через OfflineAudioContext, стереоразделение, пиковый уровень плотного микса и живой сигнал AnalyserNode. Дополнительно — реальные клавиши плетения/M/паузы, угрозы, работа без AudioContext/хранилища, очистка голосов и сохранение настроек. Потеря фокуса проверяется явной отправкой события blur в настоящий обработчик: headless Edge не переключает фокус ОС между вкладками. Субъективное качество тембров и громкость на конкретных колонках автоматикой не оцениваются.

В проверках: старт/новая попытка, невозможность сброса активного раунда, движение и плетение, поимка комара, замереть, пауза, победа/поражение, полноэкранная область и resize без потери состояния. Отдельный сценарий шёлка проверяет плетение настоящими клавишами, охоту/замах/укус богомола, отмену атаки новой развилкой и освобождение комара после разрыва. Исходные состояния для отдельных столкновений задаются явно, затем работает обычная симуляция; ИИ и ловля не подменяются. Сценарий охотника проверяет реальные клавиши: безопасное движение без плетения, дальние и близкие нити, появление/погоню/поимку, паузу, рестарт, отрыв внутри комнаты и замирание при взгляде человека. Скриншоты сохраняются в `.sharrowkin/screenshots/`, включая `hunter-warning.png`, `hunter-chase.png`, `hunter-escape.png`, `spider-volume.png`, `silk-keyboard.png`, `mantis-windup.png` и `mantis-bite.png`; `silk-lattice.png` — явно заданная тестовая радиальная сеть для проверки материалов, не автоматически созданная пауком. Проверка финала ускоряет только часы до последнего шага; это не полное ручное прохождение ночи.
